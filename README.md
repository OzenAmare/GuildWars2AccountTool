<h1> Guild Wars 2 Account Tool (until we find a better name)</h1>


<h2>What is this?</h2>

This is a tauri app in development that is going to be a player companion desktop app for GuildWars2 Player. 

It is going to pull from Arenanet's public APIs and use player data to let them browse their information in a secure and customizable manner. 

Link: https://gw2.me/

<h2>Why is this being made?</h2>

1. For fun! We enjoy writing rust code and wanted a fun rust project.
2. To explore web developemnt in the rust language.
3. To provide a unique player companion app to the GW2 space.
